✅ উত্তরমালা ও ব্যাখ্যা (Answers & Explanations) — Pages 3-5

সঠিক উত্তর হাইলাইট সহ বিস্তারিত ব্যাখ্যা

1 (B) Stack Stacks & Queues

Stack follows LIFO (Last In First Out) principle. The last element pushed is the first one popped. Queue follows FIFO.

2 (C) O(log n) Searching

Binary search halves the search space each iteration, requiring at most log₂(n) comparisons in the worst case.

3 (B) O(n log n) Complexity

By Master Theorem Case 2: T(n)=2T(n/2)+n → a=2, b=2, f(n)=n, n^(log_b a)=n. Since f(n)=Θ(n), T(n)=Θ(n log n).

4 (C) Radix Sort Sorting

Radix Sort uses digit-wise counting (non-comparison based). Quick, Merge, and Heap sort all use comparisons.

5 (C) Data and one pointer Linked Lists

A singly linked list node contains data and a single pointer to the next node. Doubly linked has two pointers.

6 (A) ABC*+ Expressions

Infix A+B*C: Operator precedence: * over +. Postfix: A + (B*C) → A + BC* → ABC*+.

7 (C) O(n) Sorting

Insertion Sort's best case is when the array is already sorted. Each element is compared once, giving O(n).

8 (B) First node Linked Lists

In a circular linked list, the last node's next pointer points back to the first (head) node, forming a circle.

9 (B) Division method Hashing

h(k) = k mod m is the division method. It's simple and commonly used, with m typically chosen as a prime number.

10 (B) 15 Recursion

Minimum moves = 2ⁿ - 1. For n=4: 2⁴ - 1 = 16 - 1 = 15 moves.

11 (B) Queue Graph Searching

BFS (Breadth First Search) uses a FIFO queue to explore nodes level by level. DFS uses a stack (or recursion).

12 (B) 3 Trees

A complete binary tree with 15 nodes: levels 0,1,2,3 → height=3 (edges from root to deepest leaf). Number of nodes = 2^(h+1)-1=15 → h=3.

13 (B) Greedy Greedy Algorithms

Fractional Knapsack allows taking fractions of items. The greedy strategy (value/weight ratio) yields the optimal solution.

14 (C) Chaining Hashing

Chaining resolves collisions by maintaining a linked list at each hash table slot. All colliding keys are stored in the same chain.

15 (B) Divide & Conquer Divide & Conquer

Merge Sort divides the array into halves, recursively sorts them, and then merges the sorted halves — classic divide & conquer.

16 (B) 48 Expressions

Postfix 5 3 + 6 *: Push 5, push 3, + → pop 3,5 → 5+3=8 push 8. Push 6, * → pop 6,8 → 8*6=48.

17 (B) Height-balanced BST Trees

AVL tree is a self-balancing Binary Search Tree where the height difference between left and right subtrees is at most 1.

18 (C) Dijkstra Shortest Path

Dijkstra's algorithm finds the single-source shortest path in a graph with non-negative edge weights.

19 (B) 2 pointers Linked Lists

A doubly (two-way) linked list has two pointers per node: one to the next node (next) and one to the previous node (prev).

20 (B) Data compression Huffman Encoding

Huffman encoding assigns variable-length codes based on frequency, achieving lossless data compression.

21 (B) Dynamic Programming Dynamic Programming

0/1 Knapsack cannot be solved optimally by greedy (fractional can). DP provides the optimal solution via subproblems.

22 (C) Tree Data Structures

Tree is a hierarchical (non-linear) data structure. Array, Stack, and Queue are all linear data structures.

23 (B) O(n²) Sorting

Quick Sort's worst case occurs when the pivot is always the smallest or largest element (e.g., already sorted array), resulting in O(n²).

24 (B) Stack Graph Searching

DFS (Depth First Search) uses a stack (explicitly or via recursion) to explore as far as possible along each branch before backtracking.

25 (B) Memory used Complexity

Space complexity measures the amount of memory an algorithm requires relative to input size, including auxiliary space.

26 (B) Largest Sorting

In Bubble Sort, each pass "bubbles up" the largest unsorted element to its correct position at the end of the array.

27 (C) Stack ADT

An Abstract Data Type (ADT) defines operations without specifying implementation. Stack, Queue, List are ADTs. Integer, Float are primitive types.

28 (A) (A*B)+(C+D) Expressions

Prefix +*AB+CD: + is root, left subtree *AB → A*B, right subtree +CD → C+D. So (A*B)+(C+D).

29 (B) Array Heaps

A heap is typically implemented using an array where parent-child relationships are determined by index calculations (i, 2i, 2i+1).

30 (B) Greedy Greedy Algorithms

Activity Selection is solved optimally by a greedy strategy: always pick the activity with the earliest finish time.

31 (B) m B-Tree

A B-Tree of order m can have at most m children per node and at most m-1 keys per node.

32 (B) DAG Graphs

Topological sorting is only possible for Directed Acyclic Graphs (DAGs). It gives a linear ordering respecting all dependencies.

33 (B) O(log n) Heaps

Inserting into a heap requires percolating up, which takes at most O(log n) comparisons/swaps (height of the heap).

34 (C) Dijkstra MST

Dijkstra finds shortest paths, not minimum spanning trees. Kruskal and Prim are MST algorithms.

35 (B) Dynamic Programming Dynamic Programming

Longest Common Subsequence (LCS) is a classic DP problem. It builds a table to find the longest matching subsequence.

36 (B) Search next slot Hashing

Linear probing handles collisions by checking the next available slot (index+1, index+2, ...) until an empty slot is found.

37 (B) T(n)=2T(n-1)+1 Recursion

To move n disks: move n-1 disks to auxiliary (T(n-1)), move the largest disk (1), move n-1 disks to target (T(n-1)). Total: 2T(n-1)+1.

38 (C) Merge Sort Sorting

Merge Sort preserves the relative order of equal elements (stable). Quick Sort and Heap Sort are typically unstable.

39 (C) Wasted space in linear queue Queues

A circular queue reuses vacated spaces at the front, preventing the "false overflow" problem of linear queues.

40 (A) LeftH - RightH AVL Tree

Balance factor = Height(Left Subtree) - Height(Right Subtree). In AVL, it must be -1, 0, or +1.

41 (A) Local optimum leads to global optimum Greedy Algorithms

The greedy choice property states that a locally optimal choice at each step leads to a globally optimal solution.

42 (B) n(n-1)/2 Graphs

A simple graph with n vertices has at most n(n-1)/2 edges (complete graph). Each pair of vertices can have at most one edge.

43 (C) Binary Search Hashing

Binary search is a searching technique for sorted arrays, not a collision resolution method. Chaining and probing are collision resolution techniques.

44 (B) n+1 Trees

In a full binary tree, leaves = internal nodes + 1. With n internal nodes, there are n+1 leaves.

45 (B) Dynamic Programming Dynamic Programming

Matrix Chain Multiplication uses DP to find the optimal parenthesization, with O(n³) time complexity.

46 (C) n-1 Sorting

Selection Sort makes exactly n-1 swaps in the worst case — one swap per pass to place each element (except the last).

47 (C) Priority Queue Shortest Path

Dijkstra's algorithm uses a min-priority queue to efficiently extract the vertex with the smallest tentative distance.

48 (C) Leaf nodes B+ Tree

In a B+ tree, all data records are stored only in the leaf nodes. Internal nodes store only keys for navigation.

49 (B) HMM decoding Dynamic Programming

The Viterbi algorithm is a DP algorithm used to find the most likely sequence of hidden states in a Hidden Markov Model (HMM).

50 (A) n/m Hashing

Load factor α = n/m, where n is the number of stored keys and m is the table size. It indicates how full the hash table is.

51 (A) Overlapping subproblems Dynamic Programming

DP requires overlapping subproblems (same subproblems solved multiple times) and optimal substructure to be efficient.

52 (A) O(n) Complexity

T(n)=T(n-1)+O(1) expands to T(n)=T(0)+n·O(1)=O(n). Example: linear search recursion.

53 (B) Bellman-Ford Shortest Path

Bellman-Ford algorithm can handle negative edge weights and detect negative cycles. Dijkstra cannot handle negative weights.

54 (B) FIFO Queues

A queue follows FIFO (First In First Out) — the first element inserted is the first one removed, like a line of people.

55 (C) O(n) Linked Lists

Searching in an unsorted linked list requires traversing all nodes in the worst case → O(n) time.

56 (B) Its correct sorted position Sorting

In Quick Sort, after partitioning, the pivot is placed at its final sorted position — all left elements are smaller, all right are larger.

57 (B) Optimal prefix codes Huffman Encoding

Huffman coding produces optimal prefix-free codes, meaning no code is a prefix of another, minimizing the total encoded length.

58 (B) Disjoint Set MST

Kruskal's algorithm uses a Disjoint Set (Union-Find) data structure to efficiently detect cycles while adding edges.

59 (C) Both Greedy and DP Algorithm Design

Optimal substructure means an optimal solution contains optimal solutions to subproblems — required by both Greedy and DP approaches.

60 (A) 2-3-4 tree B-Tree

A B-Tree of order 4 is known as a 2-3-4 tree because each internal node can have 2, 3, or 4 children.

61 (B) All-pairs shortest path Shortest Path

Floyd-Warshall computes the shortest paths between all pairs of vertices in O(n³) using DP.

62 (A) i/2 Heaps

In a 1-indexed heap array, parent of node i is at floor(i/2). Children are at 2i (left) and 2i+1 (right).

63 (B) Coins are canonical Greedy Algorithms

The greedy coin change algorithm works optimally only for canonical coin systems (like standard denominations). For arbitrary coins, DP is needed.

64 (B) Doubly linked list Linked Lists

A two-way linked list (doubly linked list) has two pointers per node — next and previous — allowing traversal in both directions.

65 (C) Both A and B Complexity

Time-space tradeoff means you can often use more memory to speed up computation (e.g., lookup tables) or use less memory with slower algorithms.

66 (C) O(nk) Sorting

Radix Sort's time complexity is O(nk) where n is the number of elements and k is the number of digits (or passes).

67 (B) Dynamic Programming Dynamic Programming

Assembly line scheduling is a classic DP problem: find the optimal path through two assembly lines with transfer costs.

68 (B) Stack Expressions

Infix to postfix conversion uses a stack to hold operators temporarily, respecting precedence and associativity rules.

69 (B) n(n-1)/2 edges Graphs

A complete graph K_n has every pair of distinct vertices connected by an edge → n(n-1)/2 edges.

70 (B) T(n)=2T(n/2)+O(n) Divide & Conquer

Merge Sort: divide into two halves (2T(n/2)) and merge them (O(n)). Total recurrence: T(n)=2T(n/2)+O(n).

71 (B) A single vertex MST

Prim's algorithm starts from an arbitrary single vertex and grows the MST by adding the cheapest edge connecting the tree to a new vertex.

72 (B) 2^L Trees

At level L (root at level 0), a binary tree can have at most 2^L nodes. Level 0: 1, Level 1: 2, Level 2: 4, etc.

73 (B) Dynamic Programming Dynamic Programming

The Bitonic Euclidean TSP is solved using DP, building optimal bitonic tours through sorted points.

74 (B) Top Stacks

In a stack, push inserts at the top and pop removes from the top — LIFO behavior. The top is the accessible end.

75 (A) O(n) Heaps

Building a heap from an unsorted array (heapify) takes O(n) time, not O(n log n), due to the decreasing work at lower levels.

76 (B) Merge Sort Divide & Conquer

Merge Sort is a classic divide & conquer algorithm: divide array, recursively sort, merge. Prim's and Dijkstra are greedy.

77 (B) Greedy (EDD) Greedy Algorithms

Minimizing maximum lateness is solved by Earliest Due Date (EDD) — a greedy strategy that schedules jobs by increasing deadlines.

78 (A) Has no collisions Hashing

A perfect hash function maps each distinct key to a unique slot with zero collisions. It's possible when the key set is known in advance.

79 (B) 5 Trees

Number of distinct binary trees with n nodes = Catalan number C_n = (2n)!/((n+1)!n!). For n=3: C_3 = 5.

80 (A) Source and sink Flow Networks

A flow network has a source (where flow originates) and a sink (where flow terminates), with capacities on edges.

81 (B) Dynamic Programming Dynamic Programming

The Principle of Optimality (Bellman) states that an optimal policy has the property that sub-policies are also optimal — foundational to DP.

82 (C) Infinite loops Algorithms

An algorithm must be finite (terminate after a finite number of steps). Infinite loops violate this fundamental property.

83 (B) Never return 0 Hashing

In double hashing, the second hash function must never evaluate to 0, otherwise the probe sequence would stall at the same slot.

84 (C) O(1) Sorting

Heap Sort is an in-place sorting algorithm — it uses O(1) extra space beyond the input array.

85 (A) N-Queens problem Backtracking

N-Queens is solved using backtracking — place queens and backtrack when constraints are violated.

86 (B) O(n) BST

In a skewed BST (essentially a linked list), searching can take O(n) in the worst case. Balanced BSTs achieve O(log n).

87 (B) Longest path Graphs

The critical path in a DAG is the longest path from start to finish, determining the minimum project completion time.

88 (B) Insertion Sort Sorting

Insertion Sort is stable — it preserves the relative order of equal elements. Selection Sort (default) is not stable.

89 (A) Fixed table size Hashing

Static hashing uses a fixed-size hash table. Dynamic hashing allows the table to grow and shrink as needed.

90 (B) Sorted ascending BST

Inorder traversal (Left → Root → Right) of a BST visits nodes in sorted ascending order due to BST properties.

91 (B) Max Flow algorithm Flow Networks

Edmonds-Karp is an implementation of the Ford-Fulkerson method using BFS to find augmenting paths, solving the max flow problem.

92 (A) 30 Expressions

Postfix 6 2 3 + *: Push 6,2,3. + → 2+3=5. Push 5. * → 6*5=30.

93 (B) 2 AVL Tree

After an insertion in an AVL tree, at most 2 rotations (a double rotation) are needed to restore balance.

94 (B) Adjacency List Graphs

For sparse graphs, adjacency lists save memory (O(V+E) vs O(V²) for matrix) and are more efficient for traversal.

95 (B) O(n³) Dynamic Programming

Matrix Chain Multiplication DP solution fills an n×n table with O(n) work per cell → O(n³) total.

96 (C) Priority Queues

A priority queue removes elements based on priority (not insertion order). The highest (or lowest) priority element is dequeued first.

97 (B) Big Omega Complexity

Big Omega (Ω) provides an asymptotic lower bound ("at least"). Big O provides an upper bound ("at most"). Theta (Θ) provides both.

98 (B) O(n) Recursion

factorial(n) makes n recursive calls: fact(n)→fact(n-1)→...→fact(0). Each call does O(1) work → total O(n).

99 (C) 16 Graphs

By Cayley's formula, the number of spanning trees in a complete graph K_n is n^(n-2). For K4: 4^(4-2) = 4² = 16.

100 (B) Merge Sort Sorting

Among comparison-based sorts, Merge Sort guarantees O(n log n) in the worst case. Quick Sort can degrade to O(n²).
