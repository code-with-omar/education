Time & Space Complexity Cheat Sheet

Data Structures & Algorithms Reference

1. Search Algorithms
Algorithm Best Average Worst Time Space
Linear Search O(1) O(n) O(n) O(1)
Binary Search (Sorted) O(1) O(log n) O(log n) O(1)
Notes:
  • Linear Search: Works on both unsorted and sorted data.
  • Binary Search: Requires data to be pre-sorted.
2. Sorting Algorithms
Algorithm Best Time Average Worst Space Stable
Bubble Sort O(n) O(n²) O(n²) O(1) ✔
Selection Sort O(n²) O(n²) O(n²) O(1) ✘
Insertion Sort O(n) O(n²) O(n²) O(1) ✔
Merge Sort O(n log n) O(n log n) O(n log n) O(n) ✔
Quick Sort O(n log n) O(n log n) O(n²) O(log n) ✘
Heap Sort O(n log n) O(n log n) O(n log n) O(1) ✘
Counting Sort O(n + k) O(n + k) O(n + k) O(k) ✔
Radix Sort O(nk) O(nk) O(nk) O(n + k) ✔
Bucket Sort O(n + k) O(n + k) O(n²) O(n) ✔
Shell Sort O(n log n) O(n3/2) O(n²) O(1) ✘

Variables Definition:

• n = Number of elements in the input dataset.
• k = Range of key values (for non-comparison sorts).
